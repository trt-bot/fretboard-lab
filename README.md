# Fretboard Lab

Guitar practice hub — woodblock metronome, chord progression explorer, and links to ear-training tools.

**Live:** [trt-bot.github.io/fretboard-lab](https://trt-bot.github.io/fretboard-lab/) (after Pages is enabled)

## Apps

| App | Description |
| --- | --- |
| **Workshop** | Holding page for practice tools |
| **Woodblock Metronome** | Natural woodblock click, tempo slider, practice timers |
| **Chord Progression Explorer** | Bluegrass, gypsy jazz, pop, and songwriting progressions with theory + playback |
| **Guitar Interval Trainer** | External ear trainer → [guitar-interval-trainer](https://trt-bot.github.io/guitar-interval-trainer/) |
